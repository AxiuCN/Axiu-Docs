# Help-Hutao-Plugin / 阿修家的小胡桃

> 源码仓库：<https://github.com/AxiuCN/Help-Hutao-Plugin>

TRSS-Yunzai v3 综合帮助插件：将机器人的全部功能按「基础 / 进阶 / 高级 / 管理员 / 插件总帮助」五级整理，命令即渲染对应帮助图。

本插件是对阿修Axiu 部署的 TRSS-yunzai 机器人（小胡桃）所有功能的帮助分类，**仅对小胡桃有效**。

## 指令说明

以下指令说明供 bot 使用者参考，标「主人」的指令仅机器主人可用。

### 五级帮助

| 指令 | 权限 | 说明 |
|------|------|------|
| `#帮助` / `#基础帮助` | 所有人 | 基础功能帮助（日常高频指令） |
| `#菜单` / `#说明` / `#功能` / `#指令` / `#命令` / `#使用说明` / `#help` | 所有人 | 一般帮助词，同样渲染基础帮助 |
| `#进阶帮助` | 所有人 | 进阶功能帮助（抽卡 / 图鉴 / 图库） |
| `#高级帮助` | 所有人 | 高级功能帮助（B站 / 面板进阶 / 日历） |
| `#管理员帮助` | 主人 | 管理员功能帮助（Bot / 图库 / 用户管理） |
| `#插件总帮助` | 所有人 | 全部插件帮助入口汇总 |

> `#喵喵帮助` 等带「喵喵」前缀的帮助命令为 miao-plugin 专属帮助，不在本插件覆盖范围。

> 五级帮助与文档站功能页面一一对应：基础功能 / 进阶功能 / 高级功能 / 管理员功能 / 插件列表。

### 综合帮助

- **描述**：基础/进阶/高级/管理员/插件 综合帮助
- **事件**：`message`
- **优先级**：1

| 正则表达式 | 处理函数 |
|-----------|---------|
| `/^(\\/\|#)?(?!喵喵)(命令\|帮助\|基础帮助\|菜单\|help\|说明\|功能\|指令\|使用说明)$/i` | basic |
| `/^#进阶帮助$/` | advance |
| `/^#高级帮助$/` | pro |
| `/^#管理员帮助$/` | host |
| `/^#插件总帮助$/` | plugins |
