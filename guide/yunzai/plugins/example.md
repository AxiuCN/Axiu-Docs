# example / 单文件插件

> 框架内置的**单文件插件**：`example/` 目录下每个 `.js` 文件就是一个完整可用的插件（目录遍历模式加载），并非示例代码，功能开箱即用，覆盖命令触发、链接解析、定时播报、入群提醒等常见场景。

## 功能简介

- **命令导出**（`cmdExport.js`）：把全部插件命令信息导出成文件（`#导出命令`，主人可用）
- **GH 仓库速览**（`GH仓库.js`）：群内发送 GitHub 仓库链接时，自动回复该仓库的信息速览图
- **下期危战**（`下期危战.js`）：查看下期危战 / 幽境的相关图片（`#下期危战`）
- **主动复读**（`主动复读.js`）：复读你发送的内容，随后撤回
- **循环播报**（`循环播报.js`）：按设定时间定时向指定群发送公告 / 问候
- **三路深渊排队**（`排队.js`）：原神深渊三路排队叫号（`#排队`）
- **赐次小说集**（`赐次小说集.js`）：小说集功能（`#赐次小说集`）
- **进群退群通知**（`进群退群通知.js`）：新人入群自动欢迎，成员退群自动提醒

### 命令速查

| 名称 | 命令 | 简介 |
|------|------|------|
| 命令导出 | `#导出命令` | 导出所有插件命令信息到文件 |
| GH仓库 | 发送 `https://github.com/...` 链接 | 自动回复仓库速览图 |
| 下期危战 | `#下期危战` / `#下期幽境` / `#下期幽境危战` | 发送指定图片 |
| 主动复读 | `#复读` | 复读内容并撤回 |
| 循环播报 | （定时任务，无命令） | 定时向指定群播报公告 |
| 三路深渊排队 | `#排队` | 深渊三路排队 |
| 赐次小说集 | `#赐次小说集` | 小说集功能 |
| 进群退群通知 | （事件触发，无命令） | 欢迎新人 / 退群通知 |

> 各功能的完整命令与详细说明见下方「指令列表」。
