# Guoba-Template-Plugin / 锅巴模板插件

> 源码仓库：<https://github.com/AxiuCN/Guoba-Template-Plugin>

---

`Guoba-Template-Plugin` 是 TRSS-Yunzai v3 的锅巴（guoba-plugin）配置规范模板，不提供实际业务功能，而是作为标准范例，供其它自研插件接入锅巴 Web 后台时参考复制。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考。

### 模板配置

本插件为锅巴配置规范模板，示例功能用于演示「锅巴 Web 保存 → 运行时读取」的配置闭环，配置通过锅巴后台可视化维护。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#模板配置` | 所有人 | 回复当前主配置与列表配置（JSON），用于确认锅巴保存的配置已生效 |

### 配置

锅巴后台 → 锅巴模板插件，可视化配置全部字段（基础配置 / 选择配置 / 高级配置）。
