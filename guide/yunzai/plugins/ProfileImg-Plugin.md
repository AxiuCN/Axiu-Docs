# ProfileImg-Plugin / 面板图图库管理器

> 源码仓库：<https://github.com/AxiuCN/ProfileImg-Plugin>

---

面板图图库管理器，为 miao-plugin 的角色面板图库提供多图库管理（主图库 / default 图库 / 第三方图库 / 屏蔽图库），支持查看、上传（含版权）、删除、重命名、屏蔽/启用、状态查看与 git 拉取更新。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 角色名与别名

指令中的「角色名」支持 miao-plugin 的角色别名（如 `#雷神面板图列表` 等价于 `#雷电将军面板图列表`），并兼容 miao-plugin 的自定义别名（`#喵喵别名设置 角色名 别名` 添加）。自定义别名配置变更后自动热更新生效，无需重启。

### 查看面板图（所有人）

角色面板图的常规查看方式。序号即列表中每张图旁边的编号，删除 / 屏蔽 / 启用等管理指令共用同一套序号。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#琴面板图列表` | 所有人 | 查看角色面板图缩略图，含作者 / 来源版权信息；超过 20 张时只显示前 20 张并提示使用可视化 |
| `#琴面板图可视化` | 所有人 | HTML 网格分页浏览该角色全部面板图（每页 20 张），适合大图库查看 |
| `#琴面板图屏蔽列表` | 所有人 | 查看该角色被屏蔽（隐藏）的面板图 |

### 图库状态（所有人）

查看图库的整体规模与更新情况。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#图库状态` | 所有人 | 主图库 + 屏蔽图库总览（角色数 / 图片数 / 大小） |
| `#主图库状态` | 所有人 | 主图库各仓库详细信息（角色 / 图片 / 大小 / 版本） |
| `#屏蔽图库状态` | 所有人 | 屏蔽图库详细信息 |

### 上传面板图（主人/授权成员）

向角色上传面板图，可标注原作者、来源与备注情况；上传后自动复制到主图库，miao-plugin 立即可见。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#添加琴面板图 张三 米游社` | 主人/授权成员 | 上传并标注版权（作者 / 来源 / 备注） |
| `#添加琴面板图` | 主人/授权成员 | 无版权上传 |

> 作者 / 来源 / 备注不允许包含下划线（`_`），否则无法解析版权信息。上传默认写入 default 图库（成员恒写 default 图库源目录）；仅主人可将手动上传目录配置为主仓库目录，此时直接写入主图库。

### 管理面板图（主人/授权成员）

| 指令 | 权限 | 说明 |
|------|------|------|
| `#删除琴面板图5` | 主人/授权成员 | 删除序号 5 的面板图（主图库真删 / default 同步删 / 第三方隐藏） |
| `#重命名琴面板图5 张三 米游社` | 主人 | 修改序号 5 面板图的版权信息（作者 / 来源 / 备注） |
| `#屏蔽琴面板图 5` | 主人/授权成员 | 屏蔽序号 5 的面板图（从查看中隐藏，可恢复） |
| `#启用琴面板图 5` | 主人/授权成员 | 解除屏蔽，恢复显示 |

### 图库更新（主人）

拉取图库最新图片。默认每天 5:30 自动更新（主图库 → 屏蔽图库 → 第三方图库 → 刷新副本，单步失败不中断），一般无需手动操作。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#主图库更新` / `#主图库强制更新` | 主人 | 拉取 / 强制重置主图库到远程最新 |
| `#屏蔽图库更新` / `#屏蔽图库强制更新` | 主人 | 拉取 / 强制重置屏蔽图库 |
| `#更新第三方图库 [图库名]` | 主人 | 更新第三方图库并同步图片到主图库（缺省=全部） |

### 第三方图库（主人）

| 指令 | 权限 | 说明 |
|------|------|------|
| `#下载第三方图库 <URL>` | 主人 | 克隆第三方图库并注册到配置 |
| `#删除第三方图库 <图库名>` | 主人 | 删除第三方图库（清理主图库副本 + 删除仓库目录） |
| `#刷新图库副本 [default/图库名]` | 主人 | 修复角色 junction 与 default/第三方副本遗漏、清理孤儿副本；无后缀=除主图库外全部 |

### 初始化与迁移（主人）

首次安装后的部署步骤（见插件仓库 README）。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#图库初始化` | 主人 | 初始化 junction，接通 miao-plugin 面板图目录 |
| `#下载主图库` / `#强制下载主图库` | 主人 | 下载 / 重下主图库 |
| `#下载屏蔽图库` / `#强制下载屏蔽图库` | 主人 | 下载 / 重下屏蔽图库 |
| `#备份图库` | 主人 | 备份旧面板图数据 |
| `#迁移图库` | 主人 | 将备份数据迁入 default 图库并复制到主图库 |

### 其他

| 指令 | 权限 | 说明 |
|------|------|------|
| `#图库帮助` | 所有人 | 查看图库管理器帮助图 |

### [面板图图库管理器]删除

- **描述**：删除面板图
- **事件**：`message`
- **优先级**：1

| 正则表达式 | 处理函数 |
|-----------|---------|
| `/^#?\\s\*(?:移除\|清除\|删除)(.+)(?:面板图)(\\d+)\\s\*$/` | delete |

### [面板图图库管理器]面板图列表

- **描述**：列出面板图（含版权信息）
- **事件**：`message`
- **优先级**：1

| 正则表达式 | 处理函数 |
|-----------|---------|
| `/^#?\\s\*(.+)(?:面板图列表)\\s\*$/` | mainList |
| `^#(.+)面板图屏蔽列表$` | blockedList |
