# ZZZ-Plugin / 绝区零插件

> 源码仓库：<https://github.com/ZZZure/ZZZ-Plugin>

---

绝区零 Yunzai-Bot 插件，提供角色面板与驱动盘评分、伤害计算、抽卡记录与分析、式舆防卫战 / 危局强袭战 / 拟真鏖战试炼 / 临界推演等战绩查询与群排名、实时便签、月度统计、卡池历史、角色攻略与图鉴等实用功能。

所有指令前缀支持 `#zzz`、`%`、`#ZZZ`、`#绝区零` 任选其一（下文以 `%` 示例）。查询类指令均依赖已绑定的米游社 CK / UID（需配合 genshin 插件的 `#扫码登录` / 绑定 CK），未绑定时会提示先绑定。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 帮助与基本信息

| 指令 | 权限 | 说明 |
|------|------|------|
| `%帮助` | 所有人 | 查看完整帮助菜单（主人额外显示管理功能） |
| `%版本` / `%插件版本` | 所有人 | 查看插件版本与更新日志 |
| `%更新日志` / `%插件更新日志` | 所有人 | 查看插件提交更新日志 |
| `%检查更新` / `%插件检查更新` | 所有人 | 检查是否有新版本 |

### 账号与设备绑定

| 指令 | 权限 | 说明 |
|------|------|------|
| `%绑定设备帮助` | 所有人 | 查看绑定设备的方法教程 |
| `%绑定设备` | 所有人 | 分步输入个人设备参数，绑定常用设备后米游社请求可显著降低账号异常（10041 等）概率 |
| `%解绑设备` | 所有人 | 解绑个人设备参数，恢复使用插件默认设备 |

> 💡 所有用户共用插件默认设备参数时较大概率触发米游社账号异常，遇到 `10041` 等错误建议自行绑定常用设备参数。绑定设备无法 100% 解决账号异常问题。

### 实时便签

| 指令 | 权限 | 说明 |
|------|------|------|
| `%每日` / `%体力` / `%便签` / `%note` | 所有人 | 查看实时便签：电池、刮刮卡、每日任务、营业状态等 |

### 角色面板

| 指令 | 权限 | 说明 |
|------|------|------|
| `%xx面板`（如 `%艾莲面板`） | 所有人 | 查询指定角色面板，包含驱动盘评分、属性、技能等 |
| `%面板列表` | 所有人 | 展示本 UID 已缓存的面板角色列表 |
| `%更新面板` / `%面板刷新` | 所有人 | 通过米游社 CK 刷新全部角色面板（有刷新冷却，默认 5 分钟） |
| `%更新展柜面板` | 所有人 | 通过 Enka 接口刷新游戏内已展示角色的面板，米游社更新报账号异常时的替代方案 |
| `%练度` / `%练度统计` | 所有人 | 驱动盘 + 技能 + 等级 + 武器 + 影画综合练度统计与排行 |
| `%原图` | 所有人 | 引用一张面板图片消息，返回该图原图 |
| `%xx伤害`（如 `%艾莲伤害` / `%艾莲伤害2`） | 所有人 | 角色技能伤害计算面板，可指定技能序号 |

> 💡 未绑定 CK 时 `%更新面板` 会自动回退为 Enka 展柜方式。若通过 Enka 更新的面板数据与实际不一致，可向仓库提交 issue。

### 抽卡记录

| 指令 | 权限 | 说明 |
|------|------|------|
| `%抽卡帮助` | 所有人 | 查看抽卡链接绑定方法教程 |
| `%抽卡链接` | 所有人 | 进入绑定流程，发送抽卡链接后自动抓取记录（建议私聊发送，群聊需开启相关配置） |
| `%刷新抽卡记录` / `%更新抽卡记录` | 所有人 | 用已绑定 CK 直接刷新抽卡记录（耗时较长） |
| `%获取抽卡链接` | 所有人（仅私聊） | 生成抽卡链接（需主人安装逍遥插件提供 stoken，国际服不支持） |
| `%抽卡分析` / `%抽卡记录` / `%抽卡统计` | 所有人 | 抽卡记录分析：五星 / UP 计数、平均出货、欧非评价 |

> 💡 链接刷新抽卡记录需主人安装[逍遥插件](https://github.com/ctrlcvs/xiaoyao-cvs-plugin)；群聊发送抽卡链接含 authkey，存在泄露风险，发送后请及时撤回。

|------|------|------|

| `%危局强袭战` / `%危局` | 所有人 | 危局强袭战战绩 |

| `%零号空洞` / `%枯萎苗圃` / `%迷失之地` | 所有人 | 零号空洞各玩法数据（`%零号空洞` 查看帮助） |
| `%区域收集` / `%探索` | 所有人 | 区域收集 / 探索进度 |

### 群排名

| 指令 | 权限 | 说明 |
|------|------|------|

| `%显示群排名` / `%隐藏群排名` | 所有人 | 开启 / 隐藏自己在群内的排名展示 |

| `%设置检查更新时间 表达式` | 设置自动检查更新的 cron 表达式 |

> 💡 攻略、图鉴功能为无专业插件时的保底方案，建议配合 Atlas、Mora-Plugin 等专业图鉴插件使用。
