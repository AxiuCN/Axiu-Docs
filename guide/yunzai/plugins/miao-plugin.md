# miao-plugin / 喵喵插件

> 源码仓库：<https://github.com/AxiuCN/miao-plugin>

---

`miao-plugin` 是 `Yunzai-Bot` 的升级插件，提供原神 / 星铁角色面板查询、伤害计算、圣遗物评分、抽卡统计、深渊统计等角色相关功能。本 fork 在保留上游全部能力的基础上，扩展了**面板变换（换装 / 属性变换 / OCR 识别）**、**最高分 / 最强面板**、**指定面板图（面板图N）**、**圣遗物初始值 / 成长值**等特色玩法。

> 更多上游功能与完整使用说明参见 [原版 README（yoimiya-kokomi）](https://github.com/yoimiya-kokomi/miao-plugin)。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 面板查询

查询角色面板数据，需先通过 `#更新面板` 获取游戏橱窗数据。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#雷神面板` | 所有人 | 查询角色面板（默认随机面板图，可加 `面板图N` 指定） |
| `#更新面板` | 所有人 | 刷新游戏橱窗详情数据 |
| `#面板角色列表` | 所有人 | 查看已获取面板数据的角色列表 |
| `#面板帮助` | 所有人 | 面板功能使用说明 |
| `#喵喵设置面板服务332` | 所有人 | 切换面板查询服务（如国服 & B 服切到 MiniGG-Api） |

> 💡 面板服务默认由 Enka.Network 提供，支持 Enka / MiniGG-Api / 米游社等多种服务源，发送 `#喵喵设置面板服务{编号}` 切换。

### 伤害计算

| 指令 | 权限 | 说明 |
|------|------|------|
| `#雷神伤害` | 所有人 | 本地计算角色伤害，可指定伤害序号（如 `#雷神伤害3`） |

伤害计算由喵喵本地完成。如结果有偏差，用 `#雷神伤害` 查看伤害加成信息；确认有误可提供伤害录屏截图及 uid 反馈。

| `#雷神遗器` | 所有人 | 星铁遗器模式 |
| `#胡桃圣遗物初始值` | 所有人 | 查看圣遗物词条初始值（fork 特色） |
| `#丝柯克圣遗物成长值` | 所有人 | 查看圣遗物词条成长值（fork 特色） |

### 面板变换（fork 增强）

通过 `换` / `补` / `变` / `改` 关键字对已查询的面板进行变换，支持换装、属性数值变换，并在伤害旁显示变化百分比（↑/↓）。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#胡桃面板 换少女头` | 所有人 | 面板换装 |
| `#胡桃面板 +30暴击 -10%大攻击` | 所有人 | 属性数值变换（`+`/`-` 前缀；百分比仅对 atk/hp/def 按基础值计算） |
| 直接发送面板截图 | 所有人 | 触发 OCR 图片识别，自动解析并应用变换 |

- 支持换武器、换圣遗物、换命座、属性变换的组合叠加
- 面板变换构建"虚拟面板"，不修改已获取的真实面板数据
- 变换后面板可与原面板对比，伤害数字旁显示差异（绿色 ↑ / 红色 ↓）

### 指定面板图（fork 增强）

查询面板时可携带 `面板图N` 独立 token（空格分隔，可出现在命令任意位置），指定使用 [ProfileImg-Plugin](https://github.com/AxiuCN/ProfileImg-Plugin) 图库中编号为 N 的面板图：

| 指令 | 权限 | 说明 |
|------|------|------|
| `#胡桃面板 面板图1` | 所有人 | 使用图库编号 1 的面板图 |
| `#胡桃面板 面板图1 换少女头` | 所有人 | 指定面板图 + 换装变换（顺序无关） |
| `#胡桃圣遗物 面板图3` | 所有人 | 圣遗物模式 + 指定面板图 |

- 编号 N 对应 ProfileImg-Plugin 主图库文件名中的序号（`角色名_n_作者_来源.ext`）
- 未指定时保持随机选图（向后兼容）；序号不存在时静默回退随机
- 面板图的上传 / 删除 / 列表等管理命令由 ProfileImg-Plugin 处理

### 最高分 / 最强面板（fork 增强）

| 指令 | 权限 | 说明 |
|------|------|------|
| `#我的胡桃最高分面板魔女4` | 所有人 | 回溯搜索圣遗物组合，评分最高的搭配 |
| `#我的胡桃最强面板魔女4` | 所有人 | 枚举散件位配置 × 坐标上升收敛，求伤害最高的搭配（需指定套装） |

- 最高分面板：mark 评分最大化，纯评分搜索
- 最强面板：同时评估伤害，结果确定可复现（非随机）
