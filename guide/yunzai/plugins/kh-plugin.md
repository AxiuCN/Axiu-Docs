# Kh-Plugin / 群成员档案

> 源码仓库：<https://github.com/yhArcadia/kh-plugin>

---

群成员昵称、群名片、头衔、权限与头像的历史记录存档插件。**记录群友的每一副嘴脸**，有效克制群友"改头换面"秽土转生。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 帮助与查询

| 指令 | 权限 | 说明 |
|------|------|------|
| `#kh帮助` | 所有人 | 查看插件帮助 |
| `#kh` / `#你是？` / `#你是谁` / `#你是什么猫猫` | 所有人 | 查询当前成员的档案信息 |
| `#开盒` | 所有人 | 查询指定成员的身份信息（按发送位置 / 回复对象确定目标） |
| `#查询信息` / `#查询信息 123` | 所有人 | 查询成员信息，可携带 QQ 号 |
| `#我的头像` / `#他(她)的头像` / `#查看头像` | 所有人 | 查看成员头像 |
| `#头像时间` / `#头像时长` | 所有人 | 查看当前头像使用时长 |

### 历史记录

| 指令 | 权限 | 说明 |
|------|------|------|
| `#历史头像` | 所有人 | 查看成员历史头像记录 |
| `#record` / `#records` | 主人 | 调试用记录接口，一般使用者无需使用 |

### 趣味排行

| 指令 | 权限 | 说明 |
|------|------|------|
| `#换头大王` / `#马甲大王` / `#专一大王` | 所有人 | 按身份变更次数 / 马甲数 / 专一度排行 |
| `#潜水大王` / `#活跃大王` / `#冒泡大王` / `#加群大王` | 所有人 | 按发言活跃度排行 |
| `#老资历` / `#小资历` | 所有人 | 按入群资历排行 |
| `#最老QQ` / `#最短QQ` / `#最新QQ` / `#最小QQ` / `#最年轻QQ` / `#最长QQ` | 所有人 | 按 QQ 号 / 年龄特征排行 |

### 备注管理

| 指令 | 权限 | 说明 |
|------|------|------|
| `#添加备注 xxx` / `#设置备注 xxx` | 所有人 | 给成员添加备注 |
| `#删除备注` | 所有人 | 删除成员备注 |

### 管理（主人）

| 指令 | 说明 |
|------|------|
| `#更新群员信息` / `#静默更新群员信息` | 手动触发群成员信息存档（静默版不发送提示） |
| `#清理幽灵记录` | 清理旧版遗留的无用记录（低于 1.13.0 的版本保留的清理功能） |
| `#删除记录1,2`（多个用逗号分隔） | 按序号删除记录 |
| `#kh统计` | 查看存档统计信息 |
| `#kh更新` / `#kh强制更新` | 更新插件（强制更新会放弃本地改动） |
| `#kh更新日志` | 查看更新日志 |
| `#kh版本` | 查看插件版本 |

## 说明

- 主动推送需在插件配置中指定目标群，否则不会推送（配置由机器主人维护）
- 记录在成员每次入群后自动留存快照，查询与排行均基于本地存档
- 身份查询结果仅展示昵称 / 群名片 / 头衔 / 头像等公开信息
