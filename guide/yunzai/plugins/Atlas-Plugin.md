# Atlas-Plugin / 图鉴插件

> 源码仓库：<https://github.com/AxiuCN/Atlas-Plugin>

---

TRSS-Yunzai v3 多游戏图鉴查询插件，支持原神 / 星铁 / 绝区零三游戏的关键词搜索与详情渲染。数据来源于 [nanoka.cc](https://nanoka.cc/)，通过 [nanoka-atlas-backend](https://github.com/MOPELotus/nanoka-atlas-backend) 子模块抓取为本地 JSON（纯文件读取，不走网络、不依赖 Redis）。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 图鉴查询

三款游戏通过不同前缀区分，输入关键词即可搜索（所有人可用）：

| 指令示例 | 游戏 | 说明 |
|------|------|------|
| `#胡桃` | 原神 | 角色查询 |
| `#雾切之回光` | 原神 | 武器查询 |
| `#绝缘之旗印` | 原神 | 圣遗物查询 |
| `*流萤` | 星铁 | 角色查询 |
| `%雅` | 绝区零 | 角色查询 |

匹配逻辑：精确匹配 → 详情页 / 多条包含匹配 → 结果列表 / 模糊匹配（逐字）→ 结果列表。

> 💡 裸角色名（如 `#胡桃`）可能被其他插件（如 miao-plugin 面板）优先响应，如需确保走图鉴请用下方快捷入口格式。

### 快捷入口与角色子视图

`#<关键词><后缀>` 形式，先于其他插件执行（所有人可用）：

| 指令示例 | 说明 |
|------|------|
| `#胡桃图鉴` | 角色图鉴（默认视图：立绘 + 基础信息 + 技能 + 命座） |
| `#胡桃天赋` | 天赋 / 技能子视图（完整参数表） |
| `#胡桃命座` | 命之座子视图 |
| `#胡桃资料` | 基础信息子视图 |
| `#胡桃故事` | 故事 / 语音子视图 |
| `#胡桃养成` | 养成 / 素材子视图 |

> 子视图仅对角色类型生效；星铁 / 绝区零仅部分子视图有数据（天赋 / 命座 / 资料可用）。

### 管理指令

| 指令 | 权限 | 说明 |
|------|------|------|
| `#图鉴初始化` | 主人 | 两阶段初始化（环境准备 → 数据抓取），自动检测上次异常中断的半成品数据 |
| `#图鉴强制初始化` | 主人 | 跳过完整性检查，强制全量重新抓取（数据损坏后重建） |
| `#图鉴更新` | 主人 | 版本检查 → 增量 → 重试 → 全量兜底，后台异步执行 |
| `#图鉴状态` | 所有人 | 查看各游戏数据版本、条目数、图片下载统计 |
| `#图鉴帮助` | 所有人 | 显示全部可用指令（主人额外可见管理指令组） |

### 定时自动更新

默认每天 5:00 自动执行增量更新（仅已初始化时运行），完成后向主人发送结果通知。包含并发锁和冷却保护，不会与手动抓取冲突。可在配置中关闭或修改 cron。

### 配置

配置文件 `config/config.yaml`，支持锅巴后台可视化配置（修改即时生效）：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `priority` | `10000` | 指令优先级，数字越小越先执行 |
| `renderScale` | `1.5` | 渲染缩放比例 |
| `notifyGroups` | `[]` | 更新完成通知的群号列表，留空仅通知主人 |
| `notifyMode` | `all` | 通知模式：all / master_only / first_master / first_master_groups |
| `autoUpdate.enabled` | `true` | 是否启用每日自动更新 |
| `autoUpdate.cron` | `0 0 5 * * *` | 自动更新 cron 表达式（6 字段：秒 分 时 日 月 周） |

### 数据说明

- 数据抓取使用 `--no-images`，条目立绘 / 图标为占位图，可后续全量抓取补齐
- 挑战页面只展示最新一期，不支持往期切换
