# genshin / 原神插件

> 源码仓库：<https://github.com/AxiuCN/Genshin-Plugin>

---

原神 / 星穹铁道 / 绝区零三合一数据查询插件：米游社数据、体力、深渊、抽卡模拟与记录、兑换码、Cookie 绑定等。

使用前需先绑定米游社 Cookie（发送 `cookie帮助` 查看教程）或绑定游戏 UID，否则无法查询个人数据。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 账号绑定

首次使用前需完成账号绑定，绑定后各查询功能自动使用你的账号数据。

| 指令 | 权限 | 说明 |
|------|------|------|
| `cookie帮助` / `体力帮助` | 所有人 | 米游社 Cookie 获取与绑定教程 |
| `cookie代码` | 所有人 | 获取提取 Cookie 用的 JS 代码 |
| `#绑定cookie` | 所有人 | 绑定米游社 Cookie（发送 Cookie 即绑定） |
| `#绑定uid` | 所有人 | 手动绑定游戏 UID（未绑定 CK 时的备选） |
| `#uid` | 所有人 | 显示当前绑定账号及已绑定的 UID 列表 |
| `#我的ck` | 所有人 | 查看当前绑定的 Cookie |
| `#删除cookie` | 所有人 | 删除当前绑定的 Cookie |
| `#配置ck` | 主人 | 添加公共查询 CK，供未绑定用户查询 |
| `#使用用户ck` | 主人 | 将用户 CK 加入公共查询池 |

> 💡 绑定 Cookie 后无需手动绑定 UID，CK 校验通过会自动同步账号下所有游戏的 UID。
