# Axiu-Plugin / 阿修插件

> 源码仓库：<https://github.com/AxiuCN/Axiu-Plugin>

---

阿修自用 Yunzai-Bot v3 插件（ESM，GPLv3），集合了米游社扫码登录、自动签到、抽卡记录、终局挑战查询与排行、验证码过码、自动入群审核、代发言等实用功能。

## 指令说明

以下指令说明供 bot 使用者（群友 / 管理员）参考，标「主人」的指令仅机器主人可用。

### 扫码登录

首次使用米游社相关功能（签到 / 抽卡 / 挑战查询）前，需要先扫码绑定账号。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#扫码登录` | 所有人 | 生成米游社二维码，扫码后自动绑定 stoken 并注入 CK 到 cookie 池。一次绑定，之后各功能自动使用你的账号 |
| `#刷新ck` | 所有人 | 用已绑定的 stoken 刷新 cookie_token 并重新绑定；`#获取ck` 仅私聊可用 |

> 💡 绑定后无需再手动 `#刷新ck`——CK 过期（retcode 10001）时插件会自动用 stoken 刷新并重试请求。

### 米游社签到

支持米游社社区 + 游戏（原神 / 星铁 / 绝区零等）每日自动签到，也可手动触发。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#注册自动签到` | 所有人 | 用已绑定的 stoken 注册当前 QQ 的签到配置，之后每日自动签到 |
| `#签到` | 所有人 | 立即手动执行当前账号的签到（兼容 `#开始签到` / `#手动签到`） |
| `#签到状态` | 所有人 | 查看已绑定账号数及每个配置的签到开关 |
| `#刷新自动签到` | 所有人 | 用 stoken 刷新当前用户所有签到配置里的 cookie |
| `#注册本群签到` | 群主/管理员 | 为群内所有已绑定 stoken 的成员批量注册 |
| `#初始化签到环境` / `#全部签到` / `#签到名单列表` | 主人 | 环境安装与批量维护 |

- 默认每日 4:30 刷新 cookie、5:00 自动签到，cron 均可配；完成后向主人与配置的群聊发送汇总
- 一个 QQ 可绑定多个米游社账号（`{qq}_1`、`{qq}_2` …），同一 stuid 自动去重
- 社区签到触发验证码时自动过码（最多重试 `signin.captchaRetries` 次）
- 锅巴「米游社签到」模块可关闭手动签到开关，关闭后 `#签到` / `#全部签到` 提示"手动签到已关闭"，自动签到不受影响

### 抽卡记录

整合米游社官方 API 与提瓦特小助手两种来源，统一存入 genshin 插件的本地抽卡存储。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#更新抽卡记录` | 所有人 | 米游社官方 API 增量更新（近 12 个月数据） |
| `#更新小助手抽卡记录` | 所有人 | 从提瓦特小助手导入全历史 UIGF 记录（已绑定 stoken 时无需提供链接） |
| `#获取抽卡链接` | 所有人（仅私聊） | 生成米游社抽卡链接供手动使用 |

- 三个命令各有独立 5 分钟冷却
- authkey 获取失败时提示发送 `#扫码登录` 重新绑定 stoken
- 导入成功后可配合其他插件的抽卡统计指令查看记录

### 终局挑战（原神 / 星铁）

查询深渊类玩法数据，群聊中查询成功会自动上报成绩并参与群排行。

**原神**

| 指令 | 说明 |
|------|------|
| `#深渊` / `#深境螺旋` | 深境螺旋查询（最高层 + 星数） |
| `#剧诗` / `#幻想真境剧诗` | 幻想真境剧诗查询（勋章、角色统计） |
| `#幽境` / `#危战` | 幽境危战查询，可指定 `单人` / `多人` / `组队` / `合作` |
| `#深渊排名` / `#剧诗排名` / `#幽境排名` / `#危战排行` | 查看群内该玩法排行 |

**星铁**（`*` 前缀，`#` 亦可）

| 指令 | 说明 |
|------|------|
| `*末日` / `*虚构` / `*忘却` / `*仲裁` | 各终局挑战数据 |
| `*深渊` | 末日 + 虚构 + 忘却三种深渊一并查询 |
| `*最新深渊` | 当前最新一期 |
| `*末日排名` / `*忘却排名` / `*虚构排名` / `*仲裁排名` | 查看群内该玩法排行 |

- 支持 `上期` / `本期`（默认本期）、`简易`（跳过详细 API）修饰符；星铁仲裁额外支持 `往期`（显示三期历史）
- 排行按赛季自动分段，综合多维度排序，数据 90 天自动过期
- 重置 / 开关排行等管理指令为 master 级（如 `#重置深渊排名`、`#开启深渊排行`、`*开启挑战排名`）

### 代发言

| 指令 | 权限 | 说明 |
|------|------|------|
| `#代@某人 消息内容` | 主人 | 以目标用户身份重新注入消息到插件流程（仅群聊） |

### 自动功能

- **自动入群审核**：加群申请按群配置黑白名单自动审批，未匹配 @ 管理员人工审核
- **米游社过码**：米游社 API 返回 Geetest 验证码（1034/10035）时自动过码（test_nine / ttocr.com / 2captcha.com + 手动打码回退）
- **CK 自动刷新**：CK 过期（10001）时自动用已绑定的 stoken 刷新 cookie 并重试请求

### 配置

锅巴后台「阿修插件」可视化配置签到、过码、入群审核等；也可手动编辑 `config/config.yaml`（签到 / 过码 / 挑战开关）、`config/group_config.yaml`（入群审核）、`config/MihoyoBBSTools_config.yaml`（签到模板）。
