# 进阶功能

抽卡模拟、抽卡记录与统计、养成计算、图鉴查询、图库查看等深度功能。

> 本页对应机器人内发送 `#进阶帮助` 查看的内容。进阶功能均在基础功能之上使用，建议先完成账号绑定。

## 抽卡模拟

| 指令 | 权限 | 说明 |
|------|------|------|
| `#十连` | 所有人 | 角色池模拟十连（每日默认一次，凌晨 4 点刷新） |
| `#十连武器` | 所有人 | 武器池模拟十连 |
| `#十连常驻` | 所有人 | 常驻池模拟十连 |
| `#定轨` | 所有人 | 武器池定轨 |

## 抽卡记录

导入游戏内抽卡链接或 UIGF 文件后，可随时查看各池记录。

| 指令 | 权限 | 说明 |
|------|------|------|
| `抽卡记录链接` | 所有人 | 发送游戏内抽卡链接导入记录 |
| `#角色记录` / `#武器记录` / `#常驻记录` | 所有人 | 各池抽取记录 |
| `#导出记录` | 所有人 | 导出为 UIGF 格式记录 |
| `#导入记录` | 所有人 | 导入 UIGF 格式记录 |
| `#更新抽卡记录` | 所有人 | 米游社官方接口增量更新 |
| `#更新小助手抽卡记录` | 所有人 | 导入提瓦特小助手全历史 |
| `#获取抽卡链接` | 所有人（仅私聊） | 生成米游社抽卡链接 |

## 抽卡统计

| 指令 | 权限 | 说明 |
|------|------|------|
| `#喵喵抽卡记录` | 所有人 | 喵喵抽卡数据分析 |
| `#喵喵抽卡统计` | 所有人 | 抽卡统计汇总 |
| `#角色统计` / `#武器统计` | 所有人 | 角色 / 武器池抽取统计 |

## 养成计算

| 指令 | 权限 | 说明 |
|------|------|------|
| `#xx突破` / `#xx素材` | 所有人 | 角色突破材料图 |
| `#xx养成` | 所有人 | 养成材料计算（如 `#刻晴养成81 90 9 9 9`） |
| `#xx攻略` | 所有人 | 米游社角色攻略 |
| `#设置默认攻略` | 所有人 | 设置默认攻略源 |

## 图鉴查询

支持三款游戏的图鉴查询：`#` 原神、`*` 星铁、`%` 绝区零。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#胡桃` | 所有人 | 原神角色 / 武器 / 圣遗物查询 |
| `*流萤` | 所有人 | 星铁角色查询 |
| `%雅` | 所有人 | 绝区零角色查询 |
| `#xx图鉴` / `#xx天赋` / `#xx命座` | 所有人 | 角色子视图 |
| `#图鉴状态` | 所有人 | 图鉴数据版本与条目数 |

## 图库查看

| 指令 | 权限 | 说明 |
|------|------|------|
| `#xx面板图列表` | 所有人 | 面板图缩略图列表 |
| `#xx面板图可视化` | 所有人 | 面板图网格分页浏览 |
| `#xx面板图屏蔽列表` | 所有人 | 查看被屏蔽的面板图 |
| `#图库状态` | 所有人 | 图库总览 |
