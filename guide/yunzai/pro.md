# 高级功能

B站动态 / 直播订阅与激励领取、面板换装与属性变换、资料日历等进阶玩法。

> 本页对应机器人内发送 `#高级帮助` 查看的内容。

## B站

LinkFlow 插件功能：登录自己的 B站账号后可订阅 UP 动态、直播开播推送，并领取激励任务。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#b站登录` | 所有人 | 扫码绑定个人 B站账号 |
| `#b站状态` | 所有人 | 查看登录状态 |
| `#订阅b站UP动态 <uid>` | 所有人 | 订阅 UP 主动态推送 |
| `#取消b站UP动态 <uid>` | 所有人 | 取消动态订阅 |
| `#动态订阅列表` | 所有人 | 查看动态订阅列表 |
| `#订阅b站UP直播 <uid>` | 所有人 | 订阅直播开播推送 |
| `#直播订阅列表` | 所有人 | 查看直播订阅列表 |
| `#激励创建配置` | 所有人 | 生成 20 槽位激励配置 |
| `#激励添加 <序号> <链接>` | 所有人 | 填入活动链接到槽位 |
| `#激励列表` | 所有人 | 查看槽位状态 |
| `#激励删除 <序号>` | 所有人 | 清空指定槽位 |
| `#领取每日激励` | 所有人 | 立即领取今日激励 |
| `#领取激励` | 所有人 | 重试抢单个 task |
