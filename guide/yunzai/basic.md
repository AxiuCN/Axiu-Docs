# 基础功能

日常高频指令：账号绑定、面板查询、体力与日常、深渊挑战与排行、签到等。绑定米游社账号后即可直接使用。

> 本页对应机器人内发送 `#帮助` / `#基础帮助` 查看的内容。

## 帮助总览

| 指令 | 说明 |
|------|------|
| `#帮助` / `#基础帮助` | 查看基础功能 |
| `#进阶帮助` | 查看进阶功能 |
| `#高级帮助` | 查看高级功能 |
| `#管理员帮助` | 查看管理员功能（仅主人） |
| `#插件总帮助` | 查看全部插件帮助入口 |

## 账号管理

首次使用前先绑定米游社账号，绑定后各功能自动使用你的账号数据。

| 指令 | 权限 | 说明 |
|------|------|------|
| `#扫码登录` | 所有人 | 扫码绑定米游社账号（stoken + CK），一次绑定全部功能可用 |
| `#刷新ck` | 所有人 | 用已存 stoken 刷新失效的 cookie |
| `#绑定cookie` | 所有人 | 发送 Cookie 绑定当前账号 |
| `#uid` | 所有人 | 查看当前绑定的 UID 列表 |
| `#我的ck` | 所有人 | 查看当前绑定的 Cookie |
| `#删除cookie` | 所有人 | 删除当前账号的绑定 |

> 💡 绑定 stoken 后 CK 过期会自动刷新，一般无需手动 `#刷新ck`。
