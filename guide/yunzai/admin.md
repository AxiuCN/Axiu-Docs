# 管理员功能

机器人主人专属的管理指令：Bot 与插件管理、图库 / 图鉴维护、用户与签到管理、排行维护等。

> 本页对应机器人内发送 `#管理员帮助` 查看的内容，**仅主人可用**。

## Bot 管理

| 指令 | 权限 | 说明 |
|------|------|------|
| `#重启` / `#关机` / `#停止` | 主人 | Bot 进程管理 |
| `#状态` / `#统计` | 主人 | 运行状态统计 |
| `#版本` | 主人 | 查看 Bot 版本 |
| `#更新` / `#强制更新` / `#全部更新` | 主人 | 更新插件 |
| `#更新日志` | 主人 | 查看更新日志 |
